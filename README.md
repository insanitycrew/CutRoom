# CutRoom

像素跃动 · 制作部

CutRoom 是一款面向短剧分析的 Windows 本地拉片工具，支持素材整理、自动拆镜、逐镜头回看、镜头笔记、离线字幕识别与中文翻译，以及拉片表导出。

视频、字幕和笔记保存在本机。软件更新通过本仓库的 GitHub Releases 分发。

## 下载与安装

适用于 64 位 Windows 10 / Windows 11。

### 首次安装

请先安装 **1.1.6 完整版**，再更新到 1.1.7。

1. 打开 [1.1.6 完整版下载页](https://github.com/insanitycrew/CutRoom/releases/tag/v1.1.6)。
2. 在 Assets 中下载以下四个文件：
   - `CutRoom-Setup-1.1.6.exe`
   - `CutRoom-1.1.6-data.7z.001`
   - `CutRoom-1.1.6-data.7z.002`
   - `CutRoom-1.1.6-data.7z.003`
3. 将四个文件放在同一文件夹，保持文件名不变。
4. 运行 `CutRoom-Setup-1.1.6.exe` 完成安装，分包无需手动解压。
5. 打开 CutRoom，点击左下角「检查更新」，升级至 1.1.7。

完整包已包含字幕模型、翻译模型和 GPU 运行组件。下载量约 4.7 GB，安装后程序目录约 6.7 GB，使用时还需预留素材与缓存空间。

**Source code（zip / tar.gz）不是安装包。**

### 已安装 1.1.6

打开 CutRoom，点击左下角「检查更新」。

发现新版本后，可选择「立即下载」或「稍后下载」。选择稍后不会下载安装文件，之后可随时再次检查更新。

下载并校验完成后，按提示退出软件安装。正常升级会保留用户数据。

### 手动更新到 1.1.7

如果自动更新连接失败：

1. 打开 [1.1.7 更新下载页](https://github.com/insanitycrew/CutRoom/releases/tag/v1.1.7)。
2. 下载 `CutRoom-Update-1.1.7.exe`。
3. 关闭 CutRoom，运行更新程序，选择原来的安装目录。
4. 更新完成后重新打开软件。

1.1.7 是约 78 MB 的小更新包，需要先安装 1.1.6，不能用于首次安装。

## 主要功能

- 按剧目、集数整理本地视频。
- 自动检测候选切镜点，支持手动拆分、合并及逐帧微调。
- 分镜条浏览、单镜头循环和时间轴定位。
- 记录画面、声音、情绪及卡点笔记。
- 离线对白识别与中文翻译，支持字幕搜索和修改。
- 导出独立 HTML 拉片表。

字幕识别在 GPU 可用时使用硬件加速，不可用时可回退 CPU。字幕和候选切镜结果均可人工修正。

## 1.1.7 更新内容

- 播放控制条调整为浅银灰半透明玻璃样式。
- 倍速、选集下拉菜单与整体界面风格统一。
- 修正分镜条切换结束时两侧卡片闪现的问题。
- 清理下载过程中重复注册的错误监听器。

## 数据保存

程序数据位于安装目录下的「用户数据」文件夹，包括笔记、字幕、缩略图、缓存、日志及导入的视频副本。

升级保留这些数据；**卸载会删除安装目录内的用户数据**。需要保留时，请提前备份。

通过接入外部文件夹读取的原视频保留在原位置。

## 常见问题

### 检查更新提示连接超时

自动更新需要能够访问 GitHub。可先在浏览器中打开：

https://github.com/insanitycrew/CutRoom/releases/latest/download/update.json

如果也无法访问，请检查网络或代理连接，或下载更新程序手动安装。

### 如何反馈问题

请提供软件版本、操作步骤和报错截图，并附上安装目录中的日志：

`用户数据/logs/desktop.log`
