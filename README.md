CutRoom 1.2.1 完整版
请直接下载本页的1.2.1完整版，不需要下载旧版本或逐个安装之前的补丁。新用户和已安装旧版本的用户都使用这套安装文件。

本版本重新整合了当前全部功能和离线组件。阿联酋部分用户更新后缺少人声分离、分类文件夹等功能，请统一安装1.2.1。

包含功能
人声与伴奏/环境声分离、独奏试听、轨迹轨道与处理进度。自动选择可用硬件，无法加速时使用CPU。
用户自建分类、浅色玻璃文件夹与封面动效。每部剧合为一张配比，多集统一统一，默认使用第一集封面。
画面标注、箭头和框选、时间轴标注点、播放器查看标注、箭头列表和独立编辑。
Ctrl+Z撤销、自定义壁纸、窗口拖动及窗口控制按钮等更新。
视频处理、字幕识别、中文翻译需要的运行环境和当前离线模型。
下载和安装
下载本页的CutRoom-Setup-1.2.1.exe和全部CutRoom-1.2.1-data.7z.00x部分包。
将安装程序与全部部分包放在同一个文件夹中，保持文件名不变，无需手动解压分包。
关闭CutRoom，运行CutRoom-Setup-1.2.1.exe。
老用户选择安装目录覆盖升级，保留用户数据；新用户选择安装目录直接安装。
只需下载 EXE 即可完成安装，全部 1.2.1 分包必须下载齐全。Windows 10/11 64 位系统适用，请至少安装 12 GB 磁盘空间，视频与服务器另需空间。
